JUtil
A Parameterized Collections Library for Java

C. Scott Ananian

JUtil is a fully-parameterized (generic) collections library for Java. It was originally part of the FLEX project.

The JUtil library is currently at version 1.5, which builds on JDK 1.5 through 8 and runs on Java 1.5 and later. You can download the latest version, see changes in the latest release, recent changes at ohloh, or browse the API documentation on-line. JUtil is licensed under the GNU GPL v2.
